# MOTION-5：上向きの黒目連動OFF・横移動幅・口の感度

利用者の依頼により、MOTION-4の上向き黒目移動を削除し、回転を変えず横移動の可動域を広げ、微細な口の動きへ反応するようにする。MOTION-4と以前のHTML・ZIP・素材・共通runtimeは保持する。

## 変更

- 通常左右/驚き左右の黒目4パーツについて、AngleYが0〜上+5度での追加移動量を0にする。顔に付いて動く頭部変形は維持し、黒目だけを上へずらす処理を外す。下向き・左右・体移動に伴う従来の視線は維持。
- 全52パーツ共通の横移動は左右各90px→135px（1.5倍）。BodyXの正規化範囲・入力感度・上下移動・AngleX/Y/Zの回転範囲は変更しない。見切れを防ぐためビューの左右余白を45pxずつ追加する。ウィンドウの縦横比によってはモデルの表示倍率が少し小さくなる。
- 口の開始は正面/閉じ口からの顎差.025、横伸び差.06、閉じる側は.012/.03へ下げる。顎だけでなく唇の横伸びも閉じ口の基準との差を使い、Cでは安定窓の中央値を記録する。非常に小さい静止ノイズは閉じたままにする。
- 開きは0〜1の連続値で、既存の時間的平滑化を使う。A/I/Eの推定を小さい動きにも対応させ、MouthFormは引き続き整数0/1/2のみ。形は補間せず、一度に一つの口パーツだけを表示する。
- 上下混入の抑制、瞬き、表情、頭の回転上限、髪/耳/衣装の動きはMOTION-4を維持。既存の有効な方向設定も引き継ぐ。

## 配布・復元

`dist/lunaris_iphone_motion_v5_mac.zip`。現在のセットを複製して保管し、ZIPのhtml・bridgeを使用中のフォルダへ置き換える。許可済み起動.commandはそのまま。古いモデルのタブを閉じて起動.commandを開き直し、MOTION-5の接続画面からモデルを開く。更新後は正面・閉じ口で静止してC。未設定の場合だけ4姿勢の初回記録が必要。

原本はviewer/tracking-input-v5.js / iphone-motion-v5.htmlとkamikan-bridge/portable-motion-v5/。回転計算は前版のviewer/iphone-motion-v4.jsをそのまま使用。再生成は `python tools/export_iphone_motion_v5.py` → `python tools/package_iphone_motion_v5_mac.py`。旧セットのバックアップで戻せる。

## 検証

Node5件・実起動1件・ブラウザ8件を確認。小さい顎/横伸びからの開き、A/I/Eの整数選択、閉じ口基準の補正、滑らかな開閉、顔喪失での閉口、前版と同じ頭角度を検査。

実中継→ブラウザで顎差.04のA、顎差.02/横伸び差.08のI、顎差.10/横伸び差.05のEが開くことを確認し、切り替え中も毎フレーム同時表示が1種類以下であることを検査。ログは `iphone-mouth-travel-v5-values.json`。上向きの追加黒目移動は通常/驚きの左右すべてで無効と同じ変形頂点になることを確認。

同じ顔角度から左右最大へ動かしたときの実頂点の移動が±135pxで、最大横移動＋頭の回転でも全パーツの頂点がビュー内であることを確認。見せ方の余白を揃えた5姿勢の描画は従来と一致。画像は `/workspace/iphone-v5-check/` に保存し、上向き・小さい口・左右最大移動を目視確認する。

確認は検証用の入力と描画で行った。実iPhoneでの感度の体感まで確認したとは報告しない。
