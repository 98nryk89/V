# 新キャラに用意する素材

まず必須なのは、正面・開眼・閉じ口の高品質な元絵と、記入した制作依頼シートです。
元絵一枚から着手できますが、下記の差分がそろうほど元の絵柄を保ちやすくなります。

| 素材 | 条件・目的 |
|---|---|
| source.png | 顔、頭頂、必要な腕・服・毛先が切れていない正面絵。実際に透明度のあるPNGを推奨 |
| hair.png | 髪だけの透明レイヤー。飾り・服・耳飾りが混ざらないもの |
| skin.png | 髪を外した顔・耳・首。隠れた範囲も描いてあると動かした際の穴が減る |
| blink_closed.png | 完全閉眼。可能なら閉じる途中の25/50/75%も用意 |
| mouth_a.png / mouth_i.png / mouth_e.png | 希望する口形。元絵と同じ位置・縮尺で、歯・口内も示す。まず一形状でも可 |
| smile.png / surprised.png | 欲しい表情だけ。顔以外の服・髪・輪郭まで変えない |
| annotations.png | 元絵のコピーに耳、金具、揺らす鎖、髪などの境界を色で説明したもの |
| references/ | 同じキャラの横顔、下向き、斜めなど。奥行きや重なりを判断する資料 |

透明に見える市松模様が画像へ描き込まれていないか、背景色を変えて確認してください。
白髪・銀髪を白背景から抜く作業は難しいため、元の透明PNGを優先します。

差分は全て同じキャンバス・位置・縮尺が理想です。別々に生成した顔で目鼻や髪が変わっている場合、
位置合わせだけでは同じ絵になりません。差分を作るときは、変える部位以外を維持します。
切り詰めたパーツだけの場合は、元絵上の貼り付け位置も添えてください。

PSDなどは原本として保持し、必要な各レイヤーを同じキャンバスサイズの透明PNGにも書き出します。
既存ツールがPSDやCubism形式を直接読み込む前提にはしません。

配置例：
```
starter/character_materials/my_character/
  brief.md
  source.png
  hair.png
  skin.png
  blink_closed.png
  mouth_a.png
  mouth_i.png
  mouth_e.png
  smile.png
  surprised.png
  annotations.png
  references/
```

ない素材は「なし」と書き、原本は加工せず保持してください。加工・配布・配信に使える範囲も伝えます。
