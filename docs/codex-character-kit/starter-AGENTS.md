# 別キャラ制作用スターター

このフォルダが制作ツールのルートです。新しいキャラはprojects/<新ID>/に分離します。
同じZIP内のinstructionsと制作依頼シートを読み、ユーザーの最新指示を優先してください。

- 原本素材・見本HTMLは保持し、見えている元絵を勝手に再生成しない。
- 顔/髪/耳/服の境界、補完、頭部形状はキャラごとに作る。見本の座標や銀髪の色条件を単純コピーしない。
- まず静止で元絵を再現し、小さい回転から追加する。耳は顔に固定、輪より下の飾りだけ揺らす。
- 眉は肌と同じ変形、髪の物理は最初はOFF。頭髪から長髪への追従は連続的につなぐ。
- 標準はHTML＋Webカメラ。iPhoneや中継は明示依頼があってから追加する。
- 仕様を変える前に既存変更を確認。専用ブランチ、1コミット1目的、完成版を保持する。
- 同時作業は同じブランチへpushせず、ファイル担当を分ける。明示依頼なしに公開やpushしない。
- 不具合はパーツを隠して原因を絞り、元絵と同寸・同姿勢の画像で確認する。
- 実機カメラ/OBSがない場合は模擬検証と区別。テスト数だけで画質を保証しない。
- 新しい仕様、原因と対策、未完了の優先順、正解画像、再生成・復元手順をこのファイルやCHANGELOGに残す。

原コードの使い方：python -m live2d_ai --help。詳細はREADME.mdを参照。
initは既存仕様を上書きするため、新規IDのみで実行。初期±30度は完成仕様ではない。
開発はPython/Chromium、認識の単体検証のみNodeを使用する。利用者はChromeだけでHTMLを開ける。
完成HTMLの顔認識データにはネット接続が必要で、完全オフラインではない。

referenceの元AGENTS/CLAUDEには過去の未完了・古い仕様が含まれる。今回の依頼と混同しない。
元キャラの全素材・マスク・Git履歴は未同梱。reference内JSONの単独ビルドはできない。
projects/owl_prince/rig_spec.jsonは追跡テスト用の参照fixtureで、再ビルドするモデルではない。新キャラは別IDを使う。
