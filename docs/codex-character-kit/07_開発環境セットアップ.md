# 制作する人向けのセットアップ

以下はCodexに実行してもらう開発手順です。完成HTMLを受け取って使うだけの人には不要です。
作業場所はZIP内のstarterです。クラウドCodexではstarterの内容を接続するリポジトリへ置きます。
README・AGENTSを読み、既存の仮想環境とブラウザがあれば再利用してください。

## Pythonと依存ライブラリ

Mac/Linuxの例：
```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```
Windowsではvenvの有効化はOSに合う手順を使います。ホスト依存の/workspaceなどをコピーしません。
Pythonは元環境の3.12で検証しています。依存はnumpy/scipy/OpenCV/Pillow/Playwrightです。
OSのターミナルと、Codexが使うクラウド側の環境は別です。

## プレビュー用のChromium

既存のChrome/ChromiumをCHROME_PATHへ設定して使うか、通常の開発PCならPlaywrightの
公式手順でChromiumを用意します（例：python -m playwright install chromium）。
管理されたクラウドでは既存ブラウザと環境の指示を優先し、独断で再インストールしません。
Macでインストール済みChromeを使う例：
```sh
export CHROME_PATH="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
```
ブラウザ取得には別途ネット接続が必要です。

## 新しいプロジェクト

character_materials/my_character/source.pngと、存在しない新IDを用意してから実行します。
```sh
python -m live2d_ai init character_materials/my_character/source.png projects/my_character
```
引数は画像→プロジェクトの順です。initは既存の仕様を上書きするため、再実行前に対象を確認します。
この時点は全身1パーツの雛形です。顔・髪・口・目を分けた完成モデルにはなっていません。
initの角度上限は±30度なので、顔の小さな回転に合わせてリグを作り直します。

新キャラ用の切り抜き・rig・頭部形状を作成した後：
```sh
python -m live2d_ai build projects/my_character
mkdir -p dist
python -m live2d_ai export projects/my_character -o dist/my_character_test.html
python -m live2d_ai preview projects/my_character --poses "left:AngleX=-5;right:AngleX=5;down:AngleY=-10;tilt:AngleZ=5;blink:EyeLOpen=0,EyeROpen=0" --out projects/my_character/check
```
必要な独立ファイルはprojects/my_characterへ、加工前の素材はcharacter_materialsへ保持します。
プレビューと完成HTMLの両方を確認し、完成後は別名で確定版を保管します。

Webカメラの認識処理だけの既存検証（任意、Nodeが必要）：
```sh
node --test tests/tracking.test.cjs
```
これは同梱した既存認識コードと見本の角度上限の検証です。新キャラの切り抜きや画質の合格を示しません。
starter/projects/owl_prince/rig_spec.jsonは、この検証が角度上限を読むための参照fixtureです。
画像やマスクを含む完全なowl_princeプロジェクトではなく、このフォルダだけではbuildできません。
新キャラ用に必要な確認は検品チェックリストから選んで実施します。
同梱tools/fidelity.pyのCLIにある顔・目の座標も見本用です。別キャラでは領域を合わせてから使い、
元の座標の数値をそのまま新キャラの合格根拠にしないでください。

ローカル開発サーバーが必要な場合：
```sh
python -m live2d_ai serve projects/my_character --port 8000
```
ターミナルに出たURLを同じPCで開きます。クラウドのlocalhostを友人への配布先として案内しません。
配布するHTMLへ画像・rig・描画・追跡コードを埋め込むexportを使えば、利用者にPythonは不要です。
顔認識用の外部データ取得にcdn.jsdelivr.netとstorage.googleapis.comへの接続が必要です。

## キットの範囲

同梱は共通ソースとプレビューの道具、認識の単体検証です。元キャラ専用のrefine_*.pyや全マスクは
同梱していません。銀髪用の色条件や専用座標を別キャラへ誤って実行しないためです。
reference/owl_prince_specsのJSONは説明用で、そのままbuildするプロジェクトではありません。
元ルナリスの再ビルドが必要なら完全な元リポジトリと制作素材を入手してください。
