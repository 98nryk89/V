このファイルをコピーして記入し、画像と一緒に制作担当へ渡してください。不明な項目は「おまかせ」、ない素材は「なし」で構いません。作り方は同梱の「03_制作調整ガイド.md」と「07_開発環境セットアップ.md」を参照してください。

- 依頼者・確認担当:
- 制作担当・ブランチ:

- 元画像の加工・配信・動画・メンバー共有の利用条件:

## 希望する動作

- 顔の回転: 基準は左右/かしげ±5度、上5度/下10度。変更希望:
- 全身の横・縦移動: 小さめ／現モデル程度／その他:
- 髪: 基準は物理揺れなし、頭髪は顔に追従、胸元以降は体と一緒。変更希望:
- 眉: 基準は肌に固定。変更希望:
- 耳: 基準は顔と同じ動きのみ。変更希望:
- 耳飾り: なし／輪より下だけ小さく揺らす／その他:
- 口形: 閉じ口＋「あ」「い」「え」／まず1種類／その他:
- 口の操作: カメラで形と開きを自動判定／その他:
- 笑顔・驚き: 自動＋手動切替／手動のみ／不要:
- 想定PC性能・重さの優先度（画質/動作速度の希望）:
- 自動表情の初期状態（例：笑顔ON・驚きOFF、または両方ON）:
- 感度: 弱い動きでは反応させない／現モデル程度／その他:
- 黒目: ごく小さく追従／固定:
- 肩の動物など: なし／独立した瞬き／その他:
- その他、動かしたい・固定したい場所:
- 特に変えてはいけない見た目:
