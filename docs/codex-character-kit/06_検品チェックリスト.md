# 完成前のチェック

各項目を「確認済み / 不合格 / 未確認 / 対象外」で記録し、画像の保存先も添えます。

- [ ] 静止で元絵と同じ大きさにそろえて比較した。
- [ ] 髪だけ、髪なし、顔だけ、飾りだけを表示し、別の部位の画素や背景片が混ざらない。
- [ ] 白・緑・暗い背景で透明度、縁の色、衣装の透けを確認した。
- [ ] 左右5度、上5度、下10度、左右かしげ、下向き＋かしげを確認した。
- [ ] 眉が肌と同じ動きで、中央のずれ・矩形のぼけ・二重線がない。
- [ ] 耳と輪が顔へ付いて動き、耳だけの揺れや変形がない。
- [ ] 髪の下地に毛束が残らず、耳下から長髪へのつながりが急に切れない。
- [ ] 首・襟に暗い汚れや透明な隙間が出ない。
- [ ] 全身を最大まで上下左右へ動かして、頭頂・腕・毛先が不自然に切れない。
- [ ] 瞬きが鮮明で、眉や前髪まで差し替わらない。
- [ ] 黒目を動かす場合は開口でクリップされ、元の黒目が下地に残らない。
- [ ] 各口形の開き0/25/50/75/100%を確認し、複数の開口素材が混ざらない。
- [ ] 笑顔・驚き・真顔・手動優先・自動判定へ戻す操作を確認した。
- [ ] 呼吸、飾りの揺れ、停止して収束する状態を確認した。
- [ ] 正面較正、顔未検出、カメラ停止、再開の動作を確認した。
- [ ] 開発ビューアだけでなく、出力したHTML自体を開いて確認した。
- [ ] 実カメラ＋OBSの録画、髪や宝石のクロマキー、負荷を利用者PCで確認した。
- [ ] 実機がない検証は「模擬入力のみ」など、未検証の範囲を明記した。
- [ ] 完成版と直前版を保持し、再生成手順と戻し方を第三者が読める。

PSNRや自動テストは補助です。サンプル固有の検査座標・数値を新キャラの合格基準にそのまま使いません。
添付素材と依頼内容が異なるため、元のルナリスと同品質を無条件に保証しないでください。
