別キャラ制作・調整用 Codex引き継ぎキット
2026年10月21日 / HTML＋Webカメラ版が標準

【このZIPを受け取った方へ】
このキットは、ルナリスの制作方法を別キャラに応用するための指示書と
共通ツールのセットです。新しいキャラのイラストはご自身で用意してください。
元絵を一枚入れ替えるだけで、自動的に同じ品質になる仕組みではありません。

【最短の始め方】
1. ZIPを解凍します。
2. 「読むための指示書.html」を開き、内容を確認します。
3. 「05_制作依頼シート.md」をコピーして記入します。不明な所は「おまかせ」でOK。
4. 新キャラの元絵・差分画像を、starter/character_materials/へ入れます。
5. Codexでstarterフォルダを作業場所にするか、starterの内容を新しいリポジトリへ
   入れてCodexから使えるようにします。クラウド版ではリポジトリの接続が必要です。
6. 「01_Codexへの最初の指示.txt」の全文をCodexへ貼り付けます。
   記入した依頼シートと画像も、Codexが読める場所へ渡してください。
7. 最初は小さな動きから作り、比較画像を確認して調整を進めます。

【入っているもの】
instructions/  依頼プロンプト、必要素材、制作手順、検品、セットアップ、引継ぎ様式
starter/       共通Pythonツール、WebGL描画、Webカメラ追跡、プレビュー用ツール
reference/     完成モデルの見本HTML、元プロジェクトの制作記録・仕様JSON
               ※仕様JSONは読解用です。専用の元画像・マスクは同梱していません。

見本を動かすだけなら、reference/owl_prince.html をGoogle Chromeで開きます。
必要なのはPC・Chrome・Webカメラ・インターネット接続です。
作る人はPython等の開発環境も必要ですが、完成HTMLを使うだけの人には不要です。
iPhone、VTube Studio、Node中継の設定を標準の手順に含める必要はありません。

【何を変更できるか】
新キャラはstarter/projects/<新しいID>/へ分けて制作します。
見本HTMLや元のモデルを上書きしません。
各キャラの髪・耳・服の境界、顔の奥行き、重なり順はキャラごとに作り直します。
既存HTMLの画像だけを差し替えて完成する、という依頼は避けてください。

【大事な限界】
本方式はLive2D風の独自WebGLモデルです。Cubismの.moc3ではなく、
VTube Studioへモデルとして読み込めるものではありません。
1枚絵の小さな回転が中心で、大きな横顔や全身の関節アニメーションは別の作業です。
顔認識にはインターネットからMediaPipe関連ファイルを取得します。
どのPCでも同じ負荷・同じ精度になることや、同品質の自動生成は保証しません。

【元のルナリスを切り抜きから再制作したい場合】
このキットには元の全画像・専用マスク・Gitの過去履歴は入っていません。
既存ルナリスの再ビルドが目的なら、配布者から完全な制作データを受け取るか、
