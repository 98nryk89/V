# 08. 使い方（トラッキング → OBS）

Web カメラで顔を動かすと、キャラが同じように動くアプリです。動かすための PC に、次の 3 つが必要です。

| 必要なもの | 備考 |
|---|---|
| **Node.js 22 以上**（LTS 版） | https://nodejs.org/ からインストール。他のパッケージのインストールは不要 |
| **Chrome**（または Edge） | トラッキングのページを開くために使う |
| **Web カメラ** | PC 内蔵のものでよい |

OBS は、配信に使うときだけ必要です。

## 1. 起動

先に、このリポジトリをダウンロードして解凍してください（GitHub の「Code」→「Download ZIP」）。`app` と `model` のフォルダは、**並べたまま**にしてください（動かすのに両方が要ります）。

### Windows
`app` フォルダの **`start.bat`** をダブルクリックします。黒い画面が開き、ブラウザで `http://localhost:8787/` が開きます。黒い画面は、使っている間、閉じないでください。

### Mac（ダブルクリックでは動きません。ターミナルで起動します）
`start.sh` は、ダブルクリックすると文字が表示されるだけで、起動しません。次の手順で、ターミナルから起動してください。

1. **Node.js を入れる**（初めてだけ）: https://nodejs.org/ から LTS 版のインストーラーをダウンロードして、インストールします。
2. **ターミナルを開く**: `Command + スペース` を押して「ターミナル」と入力し、Enter。
3. ターミナルに、半角で `cd ` と入力します。**最後に半角スペースを入れて、まだ Enter は押しません。**
4. Finder で解凍した **`app` フォルダ**を、ターミナルの画面へ**ドラッグ＆ドロップ**します（フォルダの場所が自動で入力されます）。そのあと Enter を押します。
5. 次の 1 行を入力して、Enter を押します。
   ```
   node server.mjs
   ```
6. 「V アプリを起動しました」と出れば成功です。**このターミナルは開いたまま**にして、Chrome で `http://localhost:8787/` を開きます。

うまくいかないとき（Mac）:
- 「command not found: node」と出る → 手順 1 の Node.js のインストールが済んでいません。インストール後、ターミナルを**一度閉じて、開き直して**から、手順 3 からやり直してください。
- 「No such file or directory」と出る → 手順 4 で、`app` フォルダを入れ間違えています。`cd ` の後ろをいったん消して、もう一度ドラッグ＆ドロップしてください。
- 「サイトにアクセスできません」と出る → サーバーが動いていません。ターミナルに「V アプリを起動しました」と出ているか確認してください。出ていなければ、手順 5 をもう一度行います。
- 「EADDRINUSE」と出る → すでに起動しています。先に動かしたターミナルを使うか、`Control + C` で止めてから、もう一度起動してください。

起動したら、開いたページで **「カメラを開始」** を押し、カメラの使用を許可します。

## 2. キャリブレーション（最初に 1 回）

「キャリブレーション」を押すと、画面の上に指示が出ます。1 つにつき、約 3 秒です。

1. 正面を向いて、無表情で
2. 左目だけ、ウインクして（鏡のように、あなたの左目）
3. 顔を、あなたの右に向けて
4. 顔を、上に向けて
5. 首を、あなたの右にかしげて

向きの符号や倍率を自動で合わせるので、**画面の指示どおりに、はっきり動かして**ください。結果はブラウザに保存されます。「キャリブレーションを消す」で最初からやり直せます。

## 3. 表情

画面右のボタン、またはキー **1〜6** で切り替えます。もう一度「真顔」を押すと戻ります。

| キー | 表情 |
|---|---|
| 1 | 真顔 |
| 2 | 笑顔 |
| 3 | 驚き |
| 4 | 怒り |
| 5 | 困り |
| 6 | 笑い |

表情を出している間は、あなたの口や眉の動きが、表情に少し足し合わされます。まばたきは、あなたのまばたきに合わせます。

## 4. OBS に映す

1. OBS の「ソース」の「＋」→ **「ブラウザ」** を選ぶ
2. URL に **`http://localhost:8787/player.html`** を入れる
3. 幅と高さを、配信の画面に合わせる（例: 1080 × 1350）
4. 「カスタム CSS」は空にする
5. 背景は透過で映ります。**トラッキングのページ（Chrome）は開いたままにしておく**（顔の動きを送っているのは、そのページです）

位置と大きさは、OBS 側で調整してください。ブラウザソースの URL に `?zoom=1.4&cy=0.1` のように付けると、キャラの拡大（zoom）と上下の位置（cy、プラスで上）を調整できます。

## 5. うまく動かないとき

| 症状 | 対処 |
|---|---|
| 「顔が見つかりません」 | 部屋を明るくし、カメラの正面に顔を入れる。顔が横を向きすぎていないか確認 |
| 動きが左右逆 | キャリブレーションをやり直す（手順 3 は、あなたの右に向ける） |
| 左右の目が逆に動く | キャリブレーションの手順 2（ウインク）をやり直す |
| 動きが重い | 速度の表示を確認（目安は 30 fps 以上）。他のアプリを閉じる。「GPU」ではなく「CPU」と出ていたら、ブラウザのハードウェアアクセラレーションを有効にする |
| OBS に映らない | 黒い画面（サーバー）が開いているか確認。Chrome のトラッキングページも開いたままにする |
| OBS で縁が白く（黒く）光る | OBS を再起動して、ブラウザソースの更新ボタンを押す。それでも出るときは、教えてください |

## 6. 動作確認のお願い

動かしてみたら、次を教えてください（画面の録画か、スクリーンショットがあれば、一緒にお願いします）。

- [ ] 「カメラを開始」→ 顔が追跡されて、キャラが動いたか（速度の fps はいくつか）
- [ ] 顔を左右・上下に振ったとき、キャラが同じ向きに自然に向くか（逆になっていないか）
- [ ] まばたき・口の開閉・笑顔・眉の動きが反映されるか
- [ ] 表情 1〜6 が切り替わるか
- [ ] OBS のブラウザソースに、背景が透過で映るか。縁に白や黒の線が出ないか
