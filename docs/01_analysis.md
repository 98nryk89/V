# 01. 素材解析

対象: `art/reference/fullbody.webp`（全身） / `art/reference/bustup.webp`（拡大）

## 1. 素材の現状（T0 結果）

| 項目 | 全身 | 拡大 | Live2D に必要な状態 |
|---|---|---|---|
| 解像度 | 1024×1536 | 1145×1374 | 長辺 4000px 以上（顔の横幅で 1000px 前後） |
| 顔の横幅 | 約 150px | 約 420px | 約 1000px |
| レイヤー | なし（1枚絵） | なし（1枚絵） | パーツ分けした PSD |
| 背景 | 白（アルファなし） | 白（アルファなし） | 透明 |
| 形式 | WebP（非可逆） | WebP（非可逆） | PSD（8bit RGB） |

**結論: デザインはこのまま使えるが、この画像ファイルは Cubism に直接読み込めない。**
Live2D は「パーツごとに分かれ、隠れている部分まで描き足された PSD」を変形させる仕組みのため、次の作業が必須です。

1. **高解像度化**: 約 3 倍。AI アップスケール（Real-ESRGAN など）で下地は作れるが、線のぼけと WebP の圧縮ノイズが残る。拡大は下絵として使い、パーツ分けの際に線を清書するのが前提。
2. **パーツ分け**: 目・口・髪・衣装などを別レイヤーへ分ける（`02_psd_parts.md`）。
3. **描き足し（隠れ部分の作画）**: 元絵に写っていない部分を描く。例: 前髪の下の目・眉・おでこ、閉じた目、口の中、髪やケープの裏側、首の付け根。動いたときに見える部分すべてが対象。

## 2. 2 枚の差異（どちらを正とするか決める）

モデルは 1 体分の絵柄でしか作れないため、差異は統一が必要です。**上半身は拡大版を正**とする案を推奨します（顔の情報量が多いため）。

| 箇所 | 全身 | 拡大 |
|---|---|---|
| 瞳の色 | 青寄り | 灰紫寄り |
| 耳飾り | 短め | クリスタル 3 連で長い |
| 胸元 | ベルトなし | 左胸にバックル付きベルト |
| ネクタイ | クリスタル小 | 結び目に大きいクリスタル＋チェーン |
| 白い羽装飾（肩） | 控えめ | はっきり描かれている |

下半身（ロングケープの裾・ブーツ）は全身版にしか無いので、全身モデルにする場合は全身版から起こします。

## 3. モデル範囲の提案

| 案 | 内容 | 向き |
|---|---|---|
| **A. 腰上モデル（推奨）** | 頭〜ベルト付近。配信画面での表示はほぼここ | 作業量と品質のバランスが良い |
| B. 全身モデル | ケープ裾・ブーツまで | 全身を映す企画用。ケープが大きく、作業量が A の 1.5〜2 倍程度に増える |

A で配信を始め、必要になってから全身を足すのが現実的です。

## 4. このキャラ特有の難所

| 部位 | 何が難しいか | 対策 |
|---|---|---|
| 前髪が目にかかる | 前髪の下の目を完全に描き足さないと、まばたきや角度変化で破綻する | 目・まつ毛・眉は髪に隠れる部分まで完全に描く |
| 長い銀髪（黒→銀グラデ） | 毛束が多く、ベストやケープと前後が入れ替わる | 左右 3〜5 束ずつに分けて多段物理。前後関係は「前髪束 / 体の前の束 / 体の後ろの束」の 3 層 |
| ケープ（羽状の重ね） | 枚数が多く、物理グループも多い | 腰上モデルなら肩〜胸のケープだけに絞る |
| タッセル・クリスタル・チェーン | 振り子物理が多いと、揺れがうるさく処理も重い | 目立つもの（耳飾り、髪飾りの垂れ、肩のタッセル）を優先して、残りはまとめて 1 グループ |
| フクロウ | 独立したサブキャラ。まばたき・首かしげ・羽ばたきで印象が大きく変わる | 専用パラメータ（`03_rigging.md`）。自動まばたきとホットキーで動かす |
| 仮面の髪飾り＋リボン | 頭の動きに追従させつつ、リボンだけ揺らす | 仮面は頭のデフォーマ内に入れ、リボンは物理で揺らす |
| 懐中時計 | 動かさなくても成立する | 余裕があれば針の回転・蓋の開閉（ホットキー演出） |

## 5. 品質目標（参考: 夜絆ニウ）

参考動画は YouTube にこの環境から接続できず、こちらでは中身を確認できませんでした。そのため以下は「事務所所属レベルの Live2D」で一般的に求められる水準として書いています。参考動画で特に再現したい動きがあれば教えてください。項目を追加します。

- 顔の角度 X/Y が ±30° で立体感を保つ（輪郭・鼻・耳・前髪の視差）
- まばたき・笑い目・ウインクが自然（まつ毛の形が変わる、閉じ目の曲線）
- 口の形が開閉と形状（笑顔/への字）の 2 軸で変わる。歯・舌が見える
- 視線（瞳）・ハイライトの揺れ
- 髪・装飾の多段物理（先端ほど遅れて揺れる）
- 体の X/Y/Z 回転と呼吸
- 表情差分（照れ、怒り、驚き、涙など）や腕差分をホットキーで切り替え
