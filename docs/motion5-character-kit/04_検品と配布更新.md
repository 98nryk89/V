# 検品と配布更新

## 画像で見るもの

- 元絵と静止モデルを同じ高さ・大きさに並べる。全体と、眉・耳・襟・髪の先・衣装の継ぎ目を拡大する。
- 白・緑・暗背景で、透け、背景残り、切り残し、ぼやけを確認する。
- 正面・左右・上・下・左右かしげ・下＋かしげ・最大平行移動を試す。
- 髪だけ/髪なし、飾り単体、固定下地を切り替え、別部位の巻き込みを確認する。
- 口は閉口と、あ/い/え各25/50/75/100%。同時表示、閉口でのい、笑顔との干渉を確認する。
- 瞬き・笑顔・驚きを個別に。自動笑顔が真顔で出ないかも確認する。
- 腕・頭頂・房が最大移動でも左右端で見切れないことを確認する。

## 入力で見るもの

純粋な左右入力でAngleYとAngleZを変えない。純粋な上下でAngleXとAngleZを変えない。
純粋なかしげでAngleYを変えない。位置の移動だけでうつむかない。
較正前/後、顔未検出、切断、再接続、古い中継起動中、版不一致、ブラウザ再起動を確認する。
検証用JSONの結果は実機の物理方向の証明にはならない。実iPhoneで同じ動作を確認する。

## 配布先の操作

キャラ単体のフォルダにhtml/、bridge/、起動.command、日本語説明書を入れる。
Node.js 22以上の初回導入は現方式では必要。wsはLICENSEとともに同梱すればnpm不要。
ダブルクリック→接続画面でiPhone IP→VTube Studioの第三者PC接続をON→モデル画面→初回方向設定→C。
未署名の起動ファイルはmacOSの確認が出る可能性がある。署名・公証は別工程であり、このキットは済ませていない。
既に許可した起動.commandは更新のたびに置き換えず、必要なhtmlとbridgeをセットで更新する。前版フォルダは複製保存する。

OBSではmacOS画面キャプチャでChromeのモデルウィンドウを選択する。macOSの画面収録許可が必要。
モデル表示部分を切り取り、背景を緑にしてクロマキーを適用し、ゲーム等の背景より上へ置く。
見本iPhone版の緑は#00ff00。髪・装飾が欠ける場合はキーの類似性を下げる。
Chromeを最小化せず、短く録画して口・瞬き・顔回転・音声を確認する。

## 更新と引き継ぎ

表情・口素材の追加でも旧版を残す。入力だけの修正で画像・リグを作り直さない。
制作データと書き出し手順を必ず保持し、単一HTMLだけを編集用原本にしない。
タグ/コミット、ZIP名、モデルSHA、変更点、比較画像、未確認環境、既知の問題を記録する。
「直った」は確認した範囲でのみ使う。実機未確認をソフトウェアテストの成功で置き換えない。

今回保存したMOTION-5は感度が十分と利用者評価済み。ただし閉じ口でいになることがある点は未解決。
その原因・修正完了をこの指示書は主張しない。次の閉口修正は別ブランチ・別版・単一目的で行う。
