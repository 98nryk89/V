# 検証と原因の記録

元絵と同じ縮尺で並べ、静止・左右・上下・かしげ・最大移動・口・瞬きを画像で確認する。
白/緑/暗背景、パーツ単体・非表示を使い、髪・耳・眉・襟・腕・飾りを重点検品する。
原因が実証できていない場合は仮説と書く。検証用入力と実iPhoneの結果を分ける。

## 引き継いだ注意点
- 大きい矩形で眉を切ると髪を巻き込み、眉付近に線やぼけが出る。肌と同じ固定を基本にする。
- 耳の肌や輪を揺らさない。鎖だけを別に切る。
- 髪を下地にも残すと頭を下げたとき二重に見える。全体を一律に消すと本来の髪が欠ける。
- 飾り裏を銀色で広く埋めると空間が消える。髪の輪郭と飾りの空間を個別に扱う。
- 白背景の切り抜きで白い服を消さず、画像端のフェードによる腕の透けも見る。
- 回転軸を推測してソフトウェア検査しただけでは実機の向きを検証できない。
- 中継を製品IDだけで再利用すると旧フォルダが開く。版・内容・場所を確認する。
- 基準MOTION-5では閉じ口でもいになる実機報告が残る。原因は未確定、感度は十分との評価。
