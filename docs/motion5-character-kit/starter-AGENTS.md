# 制作方針

instructionsの今回の依頼と制作依頼シートを先に読む。見本の古い履歴より今回の指示を優先する。
HTML描画＋iPhone VTube Studio追跡の新キャラ専用リポジトリ。ルナリス完成版は変更しない。
見える元絵を勝手に再生成しない。パーツの切り抜きと局所補完を記録する。
眉は肌固定、耳は頭固定、耳飾りは輪より下のみ揺れ、複雑な髪の独立揺れは初期OFF。
上下左右とかしげを分離。顔回転と全身移動を分離。閉口/あ/い/えは重複表示しない。
参照の閉口でいになる報告は未解決。原因を推測で確定しない。
専用ブランチで1コミット1目的。原本・承認済み出力・前版を保護する。
並行作業するときは担当ファイルとブランチを分ける。依頼なしに並行エージェントを追加しない。
比較画像を見てから結果を報告する。ソフトウェア検査と実iPhone/OBS確認を分ける。
日本語で短く事実を報告する。未確認なら未確認と記す。
