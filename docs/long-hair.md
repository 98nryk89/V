# 長髪の切り出しと頭への連動

「首より下の銀髪は固定」という旧仕様を、今回の指示で更新した。
旧版は長髪が body の元絵に残り、耳より上の hair_head だけが回転していた。
さらに頭部用の提供マスクに入っていない細い毛束、暗い根元が静止していた。

元絵の画素を選択するマスク hair_complete_alpha.png に、頭から左右の長髪までを統合。
長髪は手で指定した髪の芯・探索範囲・襟の除外線を使って GrabCut で分離し、細い先端は個別に指定する。
色だけで選ぶとシャツ・金属の襟・フクロウまで銀髪として拾うため、それらを保護する。
暗い根元も髪として確保し、耳の下で水平に切れないようにする。
元絵と提供マスクは上書きせず、見えている髪を生成画像に差し替えない。

頭と長髪は同じ hair_head メッシュ・同じ連続変換で動く。
高さ560pxまでの追従率は1、それより下は ((1700-y)/1140)^2 に滑らかに減衰する。
毛先の移動を控えめにし、服・時計・フクロウのリグには頭の回転を追加しない。
前髪のばねは長髪まで大きく振り回さないよう、角度と下方の重みを弱める。
髪の深度は耳の取付点と同じ121.839の平面にする。曲面の深度勾配を長髪まで使うと、
下向き＋横向きで局所的に面積が約52%まで圧縮されるため。
物理ドライバ本体は変更しない。

耳飾り裏の銀色の補完も body から髪へ移した。
顔の裏に潜り込む hair_under_face は同じ変換・深度で動く隠れた補完層。
body に銀髪の形や色を塗ったまま動かす方法は使わない。
隠れていた服と髪は近隣画素による補完なので、元絵に存在しない線画の正確な復元ではない。

再生成:

```sh
python tools/refine_cutouts.py
python tools/refine_long_hair.py
python -m live2d_ai build projects/owl_prince
python -m live2d_ai export projects/owl_prince -o dist/owl_prince.html
```

検証では、元絵と同寸の静止・上下・左右首振り・左右首かしげ・まばたき、および物理付きの連続動作を比較する。
髪だけ/髪を隠した表示でも服と髪の混入・残りを確認する。
新しい実画像テストは暗い根元・左右の長髪の確保とシャツ/襟/フクロウ/時計/鎖の除外を確認する。
実ブラウザでは両HTMLの長髪が胴体から独立して動き、胴体とフクロウの変換は一致し、
複合角度でも髪メッシュが反転しないことを確認する。

確認結果: Python 16件（リポジトリのビューア・配布HTMLの実Chromium検証2件を含む）、Node 7件が通過、スキップなし。パラメータ・表示範囲・物理ドライバ・既存の髪以外のリグ定義は変更前と同一。マスク4枚は再生成してバイト一致を確認した。
静止PSNRは変更前 full 34.25 / face 33.12 / eyes 32.79 dB、今回 full 34.28 / face 33.37 / eyes 32.68 dB。一律に画質が向上したという指標ではなく、静止の差分を記録するもの。
左右首振り・上下・左右首かしげ・まばたきと物理付き連続8フレームを目視確認。実機カメラは未確認。細い髪と服の接点、隠れていた服の模様には単一絵からの切り出し・補完の限界がある。
