# 眉周囲の線とカメラの首回転

眉の修正で使った細い多角形が、眉に重なる前髪まで眉の高さで切っていた。
髪と顔が違う面で動き、髪の中に水平な縁が見えた。
提供された hair_head_alpha.png で前髪を保護し、元から髪がない露出した眉の画素だけを顔へ戻す。
髪に多角形の横断線を作らない。耳・襟・毛先・まばたき・フクロウの仕様は維持。

[変更前・変更後・元絵の比較](brows-correction.png)

回転パラメータとリグには AngleX ±5、AngleY -10〜+5、AngleZ ±5 が残っていた。
しかしカメラ追跡は鼻・目・顎の2D比率のみを使い、取得済みの MediaPipe の3D顔変換行列を使っていなかった。
このため頭の向きを変えても小さい値しか出ない場合があった。
行列から頭のヨー・ピッチ・ロールを度で取り出し、正面との差を使って、左右5度・上5度・下10度へ追従させる。
首かしげも±5度。感度・反転スイッチは引き続き使用できる。

カメラ開始時の最初の有効な3D姿勢を基準にする。
正面を向いて「正面を較正」を押すと、回転の基準と移動の基準を更新して両方を0へ戻す。
行列がない・不正な場合は従来のランドマークによる追跡へフォールバックする。
BodyX/Y の横±90px・縦±70px、全体のリグ、物理ドライバは変更しない。

[3D姿勢入力による左右5度・上5度・下10度の描画](camera-rotation.png)

検証は Python20件（リポジトリ・配布HTMLのブラウザ検証を含む）と Node10件。
2Dランドマークを固定して3D姿勢だけ変える入力で、上記の角度と顔メッシュの変化、BodyX/Y=0を確認する。
較正・反転・不正行列のフォールバック、眉に交差する前髪を残すことも検証する。
元絵・静止・上下左右・首かしげ・瞬きの画像を比較する。実機Webカメラは未確認。

静止PSNRは full34.28 / face33.36 / eyes32.68 dB。修正前は34.28 / 33.37 / 32.68 dBで、大きな静止絵の変更はない。これは回転の合格判定ではなく差分の記録。眉のマスク3枚は再生成してバイト一致を確認した。
