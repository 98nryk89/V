# 仕上がりを保った小修正

基準はユーザーが高く評価した `99ba301`。全体の髪・顔・耳・体のリグと物理ドライバを作り直さず、以下を個別のコミットに分けた。

| 修正 | 原因と対応 | コミット |
|---|---|---|
| 人のまばたき | 段階絵の広い不透明度補間が異なるまつ毛を重ね、参考絵の肌・髪・眉のぼけまで貼り付けていた。目の範囲に絞り、提供髪マスクを除外し、切替幅を狭めて局所的に輪郭を明瞭化。閉じる45ms、閉じたまま55ms、開く80ms。カメラの目には平滑化を足さない。 | fa0ca6c |
| フクロウ | 左右の目の内側だけに白い羽の補完と閉じ目の線を追加。人とは別のタイマーで約3.8〜6.8秒ごとに瞬き。カメラ使用で人の自動瞬きが切れても続く。チェックボックスで停止でき、OwlEyeOpenでも確認できる。 | 3a803dd |
| 眉・襟 | 眉の細い線と黒い襟の一部が髪のマスクに混じり、違う面として動いていた。その画素を顔・服へ戻す。極端な角度で首と襟の間に開いていた透明な隙間は、元の白い襟の近隣色を首の裏だけに補い、黒い背景が出ないようにした。 | 09d0320 |
| 毛先2か所 | 受け入れ済みの髪マスク内から、左1451画素（髪の0.369%）、右1310画素（0.333%）だけを分割。既存PhysHairL/Rで根元0→先端へ最大±3°。通常の物理出力ではさらに小さい動き。耳や本体の髪にはこの揺れを足さない。元の位置に二重の毛先を補完しない。 | ab0a9c2 |

[まばたきの段階比較](details-blink.png) / [最大角度の襟元](details-collar.png) / [フクロウの開閉](details-owl.png) / [揺らす2か所](details-tips.png) / [独立した自動瞬きの連続フレーム](details-auto-blinks.png)

見えている人物・髪・服は元絵の画素を使う。新たに補ったのは、元絵にない閉じたフクロウのまぶたと、首に隠れていた白い襟だけ。フクロウの閉じ目は参考絵がないため近隣の白い羽と線による近似。

再生成する場合は、従来の `tools/refine_cutouts.py`、`tools/refine_long_hair.py` の後で `python tools/refine_details.py` を実行し、build/exportする。細部のマスク・補完7ファイルは再生成のバイト一致を確認済み。襟の補完を肌の境界＋2画素に限定する追補は `a496e90`。生成物は最後の配布コミットにまとめているため、修正を一つ戻した場合も再ビルド・再exportが必要。

検証: Python20件（リポジトリと配布HTMLのChromium検証を含む）、Node7件を通過、スキップなし。段階ごとの最上位まばたき絵が不透明になること、人の自動瞬きを切ってもフクロウが閉じて開くこと、毛先以外の髪・体・耳がPhysHairで動かないこと、最大角度の襟元にあった6地点の透明な隙間が埋まることを確認した。

静止PSNR: 変更前 full34.28 / face33.37 / eyes32.68 dB、変更後 full34.28 / face33.37 / eyes32.68 dB。これは静止絵の差分指標で、動作の合格判定ではない。最大の上下左右・首かしげ・体移動、瞬きの各段階、物理付きの連続描画を目視する。実機Webカメラは未確認。
