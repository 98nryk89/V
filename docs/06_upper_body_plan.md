# 06. 上半身モデルを先に作る（段階制作の計画）

## 方針（確定）

1. **上半身のみのモデルを、高品質で先に完成させる**（配信に使えるところまで）
2. 完成後に、**腰から下（ローブ・裾・ブーツ）を追加して全身にする**

「上半身モデルを作って、全身の画像に当てはめ、腰から下を足す」という理解で合っています。ただし、実際の作業は「貼り付ける」というより、**同じモデルのファイルに下半身のパーツと揺れの設定を追加する**形になります。

- 上半身の PSD と、全身の PSD は、別々のファイルとして用意する。座標のずれは、拡大版の上書きで使った位置合わせの仕組み（`tools/patch_detail.py`）で、こちらが合わせる。
- 下半身の追加は、Cubism 側のパーツ追加・PSD の差し替え機能でできる想定。外注する場合は、最初の依頼時に「後で下半身を追加する」と伝えて、できるかを確認してもらう。
- 下半身の素材は、全身版（`art/work/fullbody_x4_patched.png`）から起こす。

## 元絵

| 用途 | ファイル | 備考 |
|---|---|---|
| **上半身モデルの基準** | `art/reference/upper_body.webp`（1145×1374） | 腰・ベルト・袖口・手袋まで写っている最新の絵 |
| 4倍に拡大・背景透過 | `art/work/upper_x4_rgba.png`（4580×5496） | 済。顔の横幅は約 1700px になり、全身版の約 600px よりかなり細かい。透過の縁もきれいに抜けている |
| 全身（後から使う） | `art/work/fullbody_x4_patched.png` | 腰から下の素材元 |

上半身用の絵は、これまでの2枚の絵と細部が少し違います（ベルトが2本、タッセルの位置など）。**上半身は、この絵を正とする**のがおすすめです。全身版の腰から上は、後で作る全身版のパーツ分けの際に、この絵に合わせて描き直します。

## 準備してほしいもの

### いま必要なもの（U2 のため）
- [ ] **GPU のある環境**: VRAM 8GB 以上
  - 手元の PC に NVIDIA GPU があればそれを使う
  - 無ければ、RunPod などのクラウド GPU を数時間借りる（量子化版なら 8GB でも動く）
  - 手順は `docs/02_psd_parts.md` の A3。入力は `art/work/upper_x4_rgba.png`（U1 完了後に用意する）を使う
- [ ] **See-through のモデルのライセンス確認**: 事業で使うため、Hugging Face のモデルの重み（`layerdifforg/seethroughv0.0.2_layerdiff3d` など）のライセンスページを見て、商用利用の可否を確認する。この環境からは確認できなかった

### U4 以降に必要なもの
- [ ] **お絵描きソフト**: Photoshop か CLIP STUDIO PAINT（PSD を編集できるもの）
- [ ] **Live2D Cubism Editor 5.x（PRO 版）**: 自作する場合のみ。外注なら不要。FREE 版は規模の制限があり、この装飾量では足りない見込み
- [ ] **外注するか自作するか**: 外注するなら、次の3つをまとめて依頼できる人を探す。
  1. 仕上げ（U4）のイラスト作業
  2. Cubism のリギング（U6）
  3. 後から下半身を追加する作業
  依頼時には、`docs/02_psd_parts.md`、`docs/03_rigging.md`、`docs/05_test_plan.md` を仕様書として渡せる
- [ ] 外注する場合、**参考にしたい動き**（夜絆ニウの動画で再現したい部分）。こちらでは動画を確認できなかったので、ご自身で見て、「前髪の揺れ」「まばたき」などの項目を挙げてもらえると、仕様に追加できる

### 配信の確認（U8）のために必要なもの
- [ ] **VTube Studio**（Steam、PC 版は無料。有料の透かし除去オプションあり）
- [ ] **iPhone（Face ID 搭載機）＋ VTube Studio の iOS アプリ**: 口や眉の細かい動きを拾うために必要。Web カメラでは精度が落ちる
- [ ] **OBS Studio**
- [ ] 配信用 PC。VTube Studio と OBS を同時に動かせる GPU が必要

## 上半身モデルの品質目標
- 顔の角度は X/Y ±30° で立体感を保つ（輪郭、鼻、耳、前髪の視差）
- まばたき、笑い目、ウインクが自然
- 口は開閉と形（笑顔／への字）の2軸で変わり、歯と舌が見える
- 視線、ハイライトの揺れ
- 長い銀髪、耳飾り、髪飾り、肩のタッセル・ケープの多段の揺れ
- 体の回転と呼吸
- フクロウが独立して動く（まばたき、首かしげ、羽ばたき）
- 表情差分をホットキーで切り替えられる

## この絵の注意点
- **左右の端と下端で、ケープ・袖・手袋が切れています。** 腕や袖の続き、ケープの外側は、U4 の仕上げで描き足す必要があります（腕を動かさないモデルでも、体を傾けたときに端が見えるため）。
- 手は手袋の手首までしか写っていません。腰上モデルでは、手は画面の外に出る前提なので、手の描き足しは不要です。

腰より下は、この段階では作りません。体の下端は、画面の外に出る前提でリギングします。
