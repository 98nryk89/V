## T3 の手順（Cubism 上）
1. 目・口・眉の各パラメータを最小 → 最大まで単独で動かす
2. 角度 X/Y の 9 点（左上〜右下）それぞれで、目を閉じる・口を開ける・笑顔にする
3. 角度 Z ±30 と組み合わせても前髪と目、耳と横髪の前後関係が崩れない
4. 前髪の隙間から見える目が欠けない

## T4 の手順（Cubism 物理演算プレビュー）
1. 顔を左右にすばやく振る → 長い髪・耳飾りが 1〜2 往復で落ち着く
2. 体を傾けたまま止める → ケープ・タッセルが揺れ続けない
3. 物理の出力が他のパーツを貫通しない（髪がベストの前に回り込む等）

## T6 の手順（VTS、画面録画しながら）
1. 正面無表情でキャリブレーション
2. 左右・上下を向く（各 3 秒）
3. まばたき 5 回 → 左右ウインク
4. 「あ・い・う・え・お」をはっきり発音
5. 笑う → 眉を上げる → 眉をひそめる
6. 首を速く振る（物理の確認）
7. 10 秒静止（呼吸・フクロウのまばたきのみ動くこと）
