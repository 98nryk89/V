## 素材_materials
- `trailer_notext_video_only.mp4` / `opening_notext_video_only.mp4` … 文字を焼き込んでいない映像(音声なし)
- `text_overlays/` … 文字だけの透過PNG(1280x720)。編集ソフト側で好きなフォント・文言に差し替えできます
  - `opening_line1.png` `opening_line2.png` … 冒頭コピー(出現: 0:00.7 / 0:02.3、0:04.7〜フェードアウト)
  - `trailer_date.png` … 「2026年11月15日」(予告編 0:14.0〜)
  - `trailer_date_sub.png` … 「活動開始予定」(予告編 0:15.25〜)
- `audio_stems/` … `trailer_music.wav`(メロディ・和音・ベース) / `trailer_sfx.wav`(衝撃音・キラキラ音) / `opening_audio.wav` / `endcard_jingle.wav`
  音楽と効果音を別々に音量調整できます(予告編は2本を足すと02_trailer.mp4の音になります)。
- `images/` … `logo_nameplate_alpha.png`(ネームプレート・背景透過) / `illustration_full.jpg`(全体イラスト)
- `fonts/` … 使用フォント(Shippori Mincho、OFLライセンス)
