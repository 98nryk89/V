## 4. 依頼の経緯(要点)
1. 動画の最後に、映画予告風の演出を追加。使う素材は ネームプレート(ロゴ) と 全体イラスト と「2026年11月15日 活動開始予定」の文字。エフェクト・フォント・効果音は自由。(v1)
2. 冒頭コピーを「誰かにとっての「無価値」を 誰かにとっての「価値」に変える。」に変更し、**その部分だけアニメの冒頭へ移動**。予告編は立ち絵を使った「複数カットイン」型にする。キラキラ音と迫力は十分なので**よりメロディアスに**。**神ゲーカンパニー！を最後へ移動**。(v2)
3. 「1:14から映像が止まる」不具合の修正と、編集できる形での出力。(v3) → 依頼者から「素材ではなく編集画面を共有してほしい。指示だけでは細かい調整ができない」と要望があり、ブラウザ編集画面を作成。
4. 本引き継ぎ書の作成。

依頼者は日本語。細かい調整を自分で触りたい意向が強い。「GitHubに行く」ような遠回りの案内には不満があった → **成果物は必ずチャットに直接添付して渡すこと**。

## 5. 作り方(再現手順)
動画編集ソフトは使っていません。**Pythonで1フレームずつ描画 → ffmpegで書き出し・結合**しています。

必要環境: Python 3.13(numpy 2.5 / Pillow 12.3)、ffmpeg 6.1。`src/build.sh` を `src/` で実行すると全工程を再現できます(レンダリングに十数分かかる、4コア)。

| ファイル | 役割 |
|---|---|
| `src/make_logo_alpha.py` | ロゴの黒背景を除去して `logo.png`(透過)を作る |
| `src/audio2.py` | 音声を合成。冒頭カード用/予告編用(BGMと効果音は別WAVにも出力)/カード用 |
| `src/render.py` | 描画の共通部品(粒子、光、文字の光彩、揺れ、フラッシュ、ロゴ衝撃波など)。立ち絵画像とロゴを読み込む |
| `src/render2.py` | 冒頭カードと予告編の描画本体。`NOTEXT=1` で文字なし版。4並列で書き出し |
| `src/overlays.py` | 文字だけの透過PNGを作る |
| `src/build.sh` | 上記すべて+区間mp4+結合+編集画面用素材 |
| `src/editor.html` | ブラウザ編集画面(下の7章) |
| `src/ShipporiMincho-*.ttf` | フォント(Shippori Mincho、SIL OFL) |
| `src/illustration_full.jpg` / `src/logo.png` | 立ち絵 / ネームプレート(透過) |
| `input/` | 元のアニメ動画と、黒背景のロゴ原本 |

よく触る箇所:
- 文言・位置・大きさ: `render2.py` の `render_open()` と `logo_section()`、`overlays.py`
- カットインの内容: `render2.py` の `PANELS`(出現時刻/位置/切り抜き範囲)と `SHOTS`、`CUTS`
- 曲(コード・旋律・各音の出る時刻): `audio2.py` の `trailer()`。時刻は映像側(`HITS`/`CUTS`/10.0秒のロゴ衝突/14.0秒の日付)と**手で合わせている**ので、映像のタイミングを変えたら音の時刻も直す
- 全体の長さ: `render2.py` の `D2`(20.4)と `audio2.py` の `D`

## 6. 未確認事項と注意
- **音は私(AI)が聴いて確認できていません**。波形の音量と、映像のコマ画像の確認のみ。メロディの出来は依頼者の耳での確認待ちです。
- **ブラウザ編集画面は実際のChromeで動作確認できていません**。確認できたのは、画面表示・クリップ選択・テキスト追加と取り消し・再生ヘッドの移動(動画/音声を読めない環境のため)。映像プレビュー、音声、書き出し(MediaRecorderでの実時間録画。MP4/WebMで保存)は未検証です。動かない場合の連絡が来る前提で、最初にここを確認してください。
- 編集画面の書き出し画質は完成版より低い(軽量素材+リアルタイム録画のため)。最高画質が必要なときは、依頼者の変更内容を聞いて `build.sh` から作り直す。
- 編集画面はクリップが自動で詰まる方式(隙間を作れない)。
- 編集画面の保存: ブラウザと、ページの `db`(ドキュメント `projects/main`)に自動保存。JSONでの保存/読み込みもあり。
- 編集画面の素材(`ed/media/`)は `build.sh` の7)で作る。公開時は `editor.html` と同じ階層に置く(mp4は各15MB未満、音声はmp3。配信できる形式の制約のため)。
- 画像・動画の権利: ロゴ・立ち絵・元アニメは依頼者提供。フォントは SIL Open Font License。音楽・効果音は新規に合成。
- Git: 作業ブランチは `claude/mukachi-kachi-trailer`。`main` には直接入れていない。`out/*.zip` は `.gitignore` 済み(重複のため)。プルリクエストは未作成。

## 7. ブラウザ編集画面の仕様(後続の作業者向け)
単一のHTML(`src/editor.html`)+`media/`。機能: 映像トラックの並べ替え/トリム/分割/複製/削除、テキストレイヤー(位置・書体・色・光彩・時間・フェード)、クリップごとの音量(予告編はBGMと効果音を別々)・フェード(黒/白/クリーム)、元に戻す/やり直し、JSON保存/読み込み、動画書き出し。公開時の宣言: `capabilities: {db:{}, downloads:true}`。

編集内容(JSON)の形式:
```json
{ "v": 1,
  "clips": [ { "id":"..", "media":"open|anime|trailer|card", "in":0, "out":5.4,
               "vols":[1], "fadeIn":0, "fadeOut":0, "fadeColor":"black|white|cream" } ],
  "texts": [ { "id":"..", "text":"..", "start":0.7, "end":5.2, "x":640, "y":316, "size":54,
               "weight":700, "font":"mincho|gothic", "color":"#ffecbe", "glow":true,
               "spacing":9, "fadeIn":0.9, "fadeOut":0.5 } ] }
```
`clips` は並んだ順に隙間なく連結される(開始位置は前のクリップの終わり)。`in`/`out` は素材内の秒。`vols` は素材の音声の数だけ(予告編のみ2つ:BGM, 効果音)。`texts` の時間はタイムライン全体の秒、座標は1280x720基準で文字の中心。**依頼者がこのJSONを送ってきたら、`build.sh` の区間定義をこれに合わせて最高画質で再レンダリングできる**(文字なし映像+文字PNGを時間指定で重ねる)。

## 8. 次の担当者の最初の一手
1. 依頼者に完成版v3と編集画面の感触(特に音・メロディ、編集画面の動作)を確認する。
2. 修正指示が出たら `src/` を直して `build.sh`(必要な工程だけでも可)で再生成し、**動画をチャットに直接添付**して渡す。
3. 変更はブランチ `claude/mukachi-kachi-trailer` にコミット。編集画面を更新する場合は、同じファイルパスで再公開してURLを保つ。
